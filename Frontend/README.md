# GitHub Talent Analyzer

A Chrome Extension that analyzes GitHub profiles and provides developer insights.

## Features

- Developer Score
- Profile Analysis
- Repository Analysis
- Technology Stack Analysis
- Activity Analysis
- Repository Quality Analysis
- Portfolio Readiness
- Open Source Impact

## Tech Stack

- React.js
- Vite
- Chrome Extension Manifest V3
- GitHub REST API
